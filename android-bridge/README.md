# Tabdeal AI Bridge — Android starter

This is a minimal Android UI starter. It does not connect to a live exchange or AI service and cannot place orders. The first build is for local UI testing only.

Build with Android Studio (JDK 17+, Android SDK 35) or use the repository GitHub Actions workflow to produce a debug APK artifact.

Cloud build workflow is configured on this branch for debug APK generation.

Retry cloud build after SDK setup adjustment.
